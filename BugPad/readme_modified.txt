BugPad is a test application for QA Engineer position in Siber Systems Inc. It is intended to reproduce the functionality of Windows Notepad as close as possible, extending it in several ways (Tool Bar, Status Bar and Print Preview).

BugPad contains several intentional bugs, the goal of an applicant is to find as many of them as possible and send full error reports in English to jobs@roboform.com (plain-text format and no attachments, please).
